# Student Performance Data Analysis

## Objective
Analyze and visualize student academic performance using Pandas and Matplotlib.

## Dataset
Sample dataset: `students.csv`

## Features
- Data cleaning and basic EDA
- Summary statistics
- Filtering and grouping
- Visualization (Histogram, Bar Chart, Pie Chart)
- Export cleaned data

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
